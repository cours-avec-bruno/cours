Sommes de variables aléatoires

On additionne des dés : les espérances s’ajoutent, les variances aussi (si les lancers sont indépendants).

Deux dés : la loi de X + Y

X et Y sont les résultats de deux dés. Les 36 cases du tableau sont équiprobables (1/36 chacune). Les cases d’une même diagonale donnent la même somme : survole une diagonale ou une barre.

n dés : la loi de Sn = X1 + … + Xn

Ajoute des dés un par un. L’axe horizontal ne bouge pas : regarde la cloche avancer (l’espérance) et s’élargir (l’écart type), mais pas au même rythme.

espérance E(Sn) intervalle [E − σ ; E + σ]
Nombre de dés n
E(Sn) = n × 3,5
V(Sn) = n × 35/12
σ(Sn) = √V

L’idée

L’espérance d’une somme est toujours la somme des espérances. Pour la variance, c’est vrai quand les variables sont indépendantes : avec n dés, la variance est multipliée par n, donc l’écart type seulement par √n.

À retenir

  • E(X + Y) = E(X) + E(Y) et E(aX) = a E(X).
  • Si X et Y sont indépendantes : V(X + Y) = V(X) + V(Y). Et V(aX) = a² V(X).
  • Pour un échantillon de taille n : E(Sn) = n E(X), V(Sn) = n V(X), σ(Sn) = √n σ(X).
  • Un dé : E(X) = 3,5 et V(X) = 35/12 ≈ 2,92.
