Fonction logarithme

La fonction ln « défait » ce que fait exp : sa courbe est le reflet de celle de exp, et elle transforme les produits en sommes.

L’idée

  • Pour x > 0 : y = ln x ⇔ x = ey. Échanger x et y, c’est prendre le symétrique par rapport à la droite y = x : les courbes de exp et ln sont symétriques.
  • ln transforme les produits en sommes : ln(a × b) = ln a + ln b. Mettre deux longueurs bout à bout sur une échelle logarithmique, c’est multiplier.

À retenir

  • ln est définie et strictement croissante sur ]0 ; +∞[ · ln 1 = 0 · ln e = 1 · ln x < 0 sur ]0 ; 1[.
  • ln(a/b) = ln a − ln b · ln(an) = n ln a · ln √a = ½ ln a.
  • (ln x)′ = 1/x · limx→+∞ ln x = +∞ · limx→0⁺ ln x = −∞ (asymptote verticale x = 0).
  • ln croît très lentement : limx→+∞ ln x / x = 0.
