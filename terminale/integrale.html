Calcul intégral

L’intégrale est l’aire sous la courbe : on l’encadre par des rectangles, puis on la regarde s’accumuler.

Nombre de rectangles n

L’idée

  • Pour f positive, ∫ab f(x) dx est l’aire sous la courbe. Les sommes de rectangles l’encadrent, et l’écart tend vers 0 quand n augmente.
  • La fonction F(x) = ∫ax f(t) dt mesure l’aire accumulée depuis a : elle monte quand f > 0, descend quand f < 0. C’est la primitive de f qui s’annule en a : F′ = f.

À retenir

  • ∫ab f(x) dx = F(b) − F(a), pour n’importe quelle primitive F de f.
  • Là où f est négative, l’aire compte en négatif : l’intégrale est une aire « signée ».
  • Relation de Chasles : ∫ab + ∫bc = ∫ac · linéarité · si f ≥ 0 sur [a ; b] (a ≤ b), l’intégrale est positive.
  • Valeur moyenne de f sur [a ; b] : 1/(b − a) × ∫ab f(x) dx.
