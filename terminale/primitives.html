Primitives et équations différentielles

L’équation donne la pente en chaque point du plan : une solution est une courbe qui suit les petits segments.

Clique n’importe où sur la figure pour choisir le point de départ (x0 ; y0) : la solution qui passe par ce point se dessine.

L’idée

  • Une équation différentielle y′ = … donne, en chaque point du plan, la pente que doit avoir la solution qui y passe. Le champ de petits segments la dessine.
  • Une solution est une courbe tangente au champ partout. Par chaque point de départ passe une seule solution.

À retenir

  • F est une primitive de f sur I si F′ = f. Deux primitives diffèrent d’une constante : toutes les primitives sont F(x) + C.
  • y′ = ay : les solutions sont les fonctions x ↦ C eax.
  • y′ = ay + b (a ≠ 0) : les solutions sont x ↦ C eax − b/a. La fonction constante −b/a est la solution « d’équilibre ».
  • Une condition initiale y(x0) = y0 fixe la constante C : il reste une seule solution.
