Suites géométriques

Premier terme u0
Raison q

Pourquoi un = u0 × qn ?

Pour aller de u0 à un, on fait n pas, et à chaque pas on multiplie par q : un = u0 × q × q × … × q (n fois), et « q multiplié n fois par lui-même », c’est qn.

La grande différence avec l’arithmétique

Dans une suite arithmétique, on ajoute toujours la même quantité. Ici, la hausse vaut (q − 1) × un : elle est proportionnelle à la valeur actuelle. Regarde les blocs bleus : ils grossissent à chaque pas. C’est pour ça qu’une suite géométrique finit toujours par « exploser » quand q > 1, et qu’elle « s’écrase » vers 0 quand 0 < q < 1.

Le lien avec les pourcentages

  • Augmenter de t % revient à multiplier par 1 + t/100. Exemple : +5 % → q = 1,05.
  • Diminuer de t % revient à multiplier par 1 − t/100. Exemple : −20 % → q = 0,8.

À retenir

  • Avec u0 > 0 : q > 1 → croissante · 0 < q < 1 → décroissante · q = 1 → constante.
  • Pour reconnaître une suite géométrique : le quotient un+1 ÷ un est toujours le même.
  • Les points ne sont pas alignés : ils dessinent une courbe qui se redresse de plus en plus (croissance exponentielle).
