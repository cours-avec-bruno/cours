Raisonnement par récurrence

Pour prouver qu’une propriété P(n) est vraie pour tous les entiers, on fait tomber des dominos.

Chaque domino est une propriété : P(0), P(1), P(2)… « Le domino tombe » veut dire « la propriété est vraie ». Pour que tous tombent, il faut deux choses : que le premier tombe (initialisation), et que chaque domino qui tombe fasse tomber le suivant (hérédité : si P(n) est vraie, alors P(n + 1) aussi).

Clique entre deux dominos pour les écarter : l’hérédité ne marche plus à cet endroit.

Un exemple qu’on voit

P(n) : « 1 + 3 + 5 + … + (2n − 1) = n² ». La somme des n premiers nombres impairs est un carré. Ajoute des couches : chaque nouvelle couche (en bleu) contient le nombre impair suivant, et le carré grandit d’un rang.

La rédaction type

  • Initialisation. Pour n = 1 : 1 = 1². Donc P(1) est vraie.
  • Hérédité. On suppose P(n) vraie pour un entier n (hypothèse de récurrence) : 1 + 3 + … + (2n − 1) = n². Alors 1 + 3 + … + (2n − 1) + (2n + 1) = n² + 2n + 1 = (n + 1)². Donc P(n + 1) est vraie.
  • Conclusion. P(1) est vraie et P est héréditaire, donc P(n) est vraie pour tout n ≥ 1.

À retenir

  • Sans initialisation, rien ne démarre : l’hérédité seule ne prouve rien.
  • Sans hérédité, la chaîne s’arrête : vérifier quelques cas ne suffit jamais.
  • Dans l’hérédité, on ne démontre pas P(n) : on l’utilise pour obtenir P(n + 1).
